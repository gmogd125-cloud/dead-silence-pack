DEAD SILENCE — Installation Guide
=================================

A Minecraft horror pack. Monsters hear your real microphone. Do not make a sound.
Minecraft 1.20.1, Forge 47.4.10. No server needed. 27 mods; the first install downloads them all.

Voice recording
---------------
Revervox, Mimicked and SimpleMimics record short clips of your voice so monsters can repeat them. You and the host have both agreed to this.
Clips are saved as files on the HOST's computer. Voice Chat Recording's Privacy Mode is OFF and Mimicked recording is ON in this pack.

Install (once)
--------------
1. Download ATLauncher from https://atlauncher.com and install it. Log in with your Minecraft account.
2. Put DEAD_SILENCE.zip (or DEAD_SILENCE.mrpack, same file) anywhere (Downloads is fine). Do not unzip it.
3. In ATLauncher click the "Instances" tab, then the "Import" button (or "+ Import Instance"),
   and choose DEAD_SILENCE.zip.
4. Name it DEAD SILENCE and click Import / Install. It downloads Minecraft, Forge and all mods by itself.
   Wait until it finishes. The first install takes a few minutes.
5. In ATLauncher, open the instance's Settings and set Maximum Memory (RAM) to 6144 MB
   (8192 MB if you have 16 GB or more; 4096 MB may stutter with this many mods). Close Settings.

Launch
------
1. Click Play on DEAD SILENCE. The first start is slow. Essential may ask you to sign in or accept terms: accept.
2. Allow Java through Windows Firewall if Windows asks. Allow BOTH private and public networks.
3. Microphone: in the game open Esc > Options > Voice Chat (or the voice chat key, shown in Options > Controls). Pick your microphone and run the microphone test.
   Turn on noise suppression if available. Use Voice Activation, not Push To Talk, so monsters can hear you.
   (If you use Push To Talk, monsters only hear you while you hold the key.)
   Whispering: hold the whisper key (set in Controls > Voice Chat).

Join your friend
----------------
1. Your friend (the host) opens their world with Essential and sends you an invite.
2. Accept the invite in Minecraft (a message shows up in the Essential social menu, press the Essential friends key
   or open Multiplayer / Essential).
3. If you cannot hear each other, see the voice section in HOST_NOTES.txt. The host has to do one extra step.

Dark and the monsters
---------------------
- Sometimes a "player" with a friend's name, skin and voice shows up. It can be a Mimic (SimpleMimics mod). If your friend's voice
  sounds off, or they do not answer in chat, do not trust it. Ask them something only they would know.
- Caves and nights are truly dark (Pitch Dark mod). Bring torches. You only see a few blocks around you in the dark.
- Monsters are rare on purpose and each lives in certain places: caves, forests at night, open plains, mountains, deserts.
- Many of them hunt by sound. Speaking, mining and fighting carry. Whisper (hold the whisper key), crouch, or stay quiet.
- Walls block sound. Hiding behind blocks helps. Your base is usually safe, not always.

Tips
----
- Quiet is safe. Whisper is safer than talking. Sound of fighting and mining also draws attention.
- Dark caves are where the worst things are.
- If the game crashes on start: lower RAM to 4096, close other programs, and tell the host what the crash window says.

Updates
-------
Latest file and page: https://gmogd125-cloud.github.io/dead-silence-pack/
When a new version is out, Minecraft marks the Mods button on the title screen. Open Mods and look at "DEAD SILENCE Modpack".
(The mark can also light up for other mods that have newer versions; this pack is pinned on purpose, ignore those.)
To update: download the new file from the page and import it as a new instance. Copy your old instance's saves folder over if you want to keep a world.
