# DEAD SILENCE

Multiplayer voice horror modpack for Minecraft 1.20.1 (Forge 47.4.10), importable into ATLauncher.

- Page and download: https://gmogd125-cloud.github.io/dead-silence-pack/
- Latest file: https://github.com/gmogd125-cloud/dead-silence-pack/releases/latest/download/DEAD_SILENCE.mrpack
- Mod list with versions and hashes: [MANIFEST.md](MANIFEST.md)

The pack file holds no mod jars, only download links and hashes (Modrinth), small configs and a datapack.
Revervox, Mimicked and SimpleMimics record short voice clips so monsters can repeat them. SimpleMimics is by AkaneDev.

## Releasing an update

1. Build the new `.mrpack` and bump the version in `docs/update.json` (`1.20.1-latest`, `1.20.1-recommended` and a changelog line).
2. Create a GitHub release with the new `DEAD_SILENCE.mrpack` and `DEAD_SILENCE.zip`.
3. Push. Players see an update notice on the Mods button after Pages refreshes.
