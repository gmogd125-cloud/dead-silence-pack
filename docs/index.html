DEAD SILENCE

Multiplayer voice horror for Minecraft 1.20.1 (Forge). Monsters hear your microphone. Do not make a sound.

The file holds no mod files. ATLauncher downloads every mod from Modrinth when you import it.

Install (once)

  1. Install ATLauncher and sign in with your Minecraft account.
  2. Instances tab, then Import, then choose the downloaded file. Do not unzip it.
  3. Set the instance's memory to 6144 MB (8192 MB if you have 16 GB or more).
  4. Play. Set your microphone in Options > Voice Chat. The host opens a world with Essential and invites you.

Updates

The pack contains a small marker mod. When a newer version is out, Minecraft's own update checker shows an update available notice on the Mods button of the title screen and in the Mods list. To update: download the newest file from this page, import it in ATLauncher as a new instance, and (if you want to keep a world) copy the old instance's saves folder over. Both players should be on the same version.

Voice recording

Revervox, Mimicked and SimpleMimics record short clips of your voice so monsters can repeat them. By using this pack you agree to that. Clips can be saved on the host's computer. Do not use the pack with people who have not agreed.
